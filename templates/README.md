# Safety templates and abbreviation list

Printable versions of the forms in the Varia Connect app. **Word** files are for editing (add your company logo and form numbers); **PDF** files are ready to print. `pdf/00_All-Safety-Templates.pdf` is the full set in one file for a site pack.

These are draft templates based on typical Malaysian practice (OSHA 1994, BOWEC 1986, DOSH HIRARC Guidelines 2008, DOSH Confined Space ICOP 2010, NADOPOD 2004). Your SHO must review them before use on site.
