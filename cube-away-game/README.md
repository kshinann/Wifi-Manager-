# Cube Quest: 3D Arrow Puzzle

A CubeAway-style puzzle game built with **React Native + Expo + Three.js (react-three-fiber)**.

Arrows wrap around a 3D shape. Tap an arrow and it slides off in the direction it points,
but only if nothing is in its way. Clear every arrow to finish the stage. Drag to rotate the shape.

## Features

- **5 story chapters, 40 levels.** Pip the fox and Luma untangle the Knot Weaver's Light Cubes.
  1. 🌲 Whispering Forest: tutorial, 3×3 → 6×6 cubes, 5 hearts
  2. 🐚 Coral Ocean: longer arrows, cuboids, first pyramid
  3. 🌃 Neon City: **timed** stages
  4. 🏜️ Desert Temple: **1–2 mistakes allowed**, pyramids and star crosses
  5. 🌌 Starlight Fortress: giant 10–14 cubes and mixed modes
- **Shapes:** cube, cuboid, stepped pyramid, 3D star cross. Any voxel shape works (see `src/game/shapes.ts`).
- **Stage types:** limited mistakes (hearts), time limit, and **boss stages** where clearing arrows reveals a picture painted on every face.
- **Always solvable, no dead ends.** The generator guarantees it, and the unit tests check every level.
- Hints (highlight a free arrow), Undo (takes back your last mistake), sound effects, haptics.
- Star rating, saved progress, chapter/level unlocking, a world map, and story cutscenes.
- Placeholder ad/IAP hooks in `src/services/monetization.ts` (rewarded ads for hints/undo/continue, shop).

## Run it

```bash
cd cube-away-game
npm install
npx expo install --fix   # aligns native module versions with your Expo SDK
npx expo start           # then press a (Android), i (iOS) or w (web)
```

Use the **Expo Go** app on your phone to scan the QR code.

## Tests

```bash
npm test
```

This builds and solves all 40 levels, checks that arrows never overlap, and checks that random play can never get stuck.

## Project layout

```
App.tsx                  simple screen router (title → map → story → game)
src/game/                pure TypeScript puzzle engine (no React)
  shapes.ts              voxel shapes
  surface.ts             exposed faces = playable cells, edge-wrapping movement
  generator.ts           solvable puzzle generator + escape-ray logic
  puzzle.ts              runtime state (what blocks what)
  pictures.ts            boss-stage emblems
  level.ts               builds a level from its spec, star rating
src/data/chapters.ts     chapters, themes, story text, level list (tune difficulty here)
src/render/              three.js scene: surface mesh, instanced arrows, sky + particles
src/screens/             Title, World map, Story, Game
src/services/            audio, haptics, monetization placeholders
assets/sounds/           generated by `npm run gen:sounds`
```

## Adding a level or a shape

Add an entry to a chapter's `stages(...)` list in `src/data/chapters.ts`, for example
`{ shape: cross(11, 3), lives: 2, secondsPerArrow: 4, maxLen: 10 }`.
To add a new shape, add a case to `buildVoxels` in `src/game/shapes.ts` that fills a set of voxels.
Movement, generation and rendering all work from the voxel set automatically.
