# Varia Connect

Draft construction site management app for Malaysian contractors: safety, site operations, drawings, BQ & cost, materials, subcontractors, plant, site network, and a guide to abbreviations and standards.

- **Web mockup:** `mockup/sitelink.html` (open in any browser)
- **Android test app:** `android/`, built by GitHub Actions; download the APK from the latest `test-build-*` release
- **Printable safety templates & abbreviation list:** [`templates/`](templates/README.md)

All data is sample data. See `HANDOFF.md` for project status and how to continue.
